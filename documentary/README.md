# 机器人走起来之后

GenieSim × StreamVLN 技术纪录片的可编辑制作工程。画面从真实数据出发：相机回放、训练记录、同起点的模型轨迹，再解释失败和下一步可以验证的问题。

当前交付是 **78 秒视觉样片**，不是完成配音的发布成片。声音来源、听感与最终发布尚待确认；不会把旧音轨或静音预演当作新视频上传。四个平台目前只有[本地策划](content/platforms.json)，没有上传、提交或公开链接。

## 先看什么

- [七段故事板](content/sample.json)：镜头、旁白、预排字幕、来源、时长与指标引用。
- [自然口播稿](content/narration.md)：短句、明确停顿，不模仿某位真人。
- [事实契约](content/contract.md)：指标来自原始 JSON，绝不把控制器验证当成模型成绩。
- [视觉样片验收](evidence/visual-preview-verification.json)：51 项测试、完整解码、黑帧／静态段检查及抽样 OCR；不等于配音成片验收。
- [依赖安全边界](security/README.md)：npm 审计零告警，但上游预打包代码仍有已记录的残余风险。

样片采用全中文说明、米白与深色的克制排版。技术名称和真实源图中的原始字段予以保留。历史 Base/LoRA 的 success@0.5m 都是 0/10；新版模型栈的 CPU 验证不是新的导航成绩。

## 本地预览

使用 Node.js 22.13 或更新的 22.x，以及可执行的 FFmpeg/FFprobe。从仓库根目录运行：

```sh
cd documentary
npm ci --ignore-scripts
npm run check:facts
npm test
npm run test:coverage
npm run lint
node scripts/media.mjs --prepare --decode
npm run dev -- --no-open --port=3117
```

打开 `http://127.0.0.1:3117`。必须使用 `npm run dev`：它采用本项目的 loopback 启动器，不向局域网开放 Studio。不要照版本警告把 Zod 降回存在公告的旧版本。

如需导出供审阅的无声视觉版，运行 `npm run render:preview`，输出为 `out/visual-sample-silent.mp4`。导出不代表发布门通过；它明确没有音轨，不是可直接投稿的最终版本。

素材准备仅从固定 Git 提交提取三份已校验的小文件，不下载模型、原始数据集或整个 Release 归档。若浅克隆没有该提交，可先在仓库根目录运行：

```sh
git fetch --depth 1 origin 2b1532b034b84cb00fe8e9c718caf768a4589d6a
```

`public/media/` 与 `out/` 都被 Git 忽略。准备脚本校验 SHA-256、媒体解码、分辨率、帧率和源片时长；字节不匹配时拒绝继续。当前本机使用 PingFang SC 等系统字体，不再分发系统字体；跨平台渲染需要自行配置有许可的中文字体，并复核换行。

覆盖率命令串行运行，统计事实／媒体辅助脚本与启动器，不把测试文件自身计入，也不宣称覆盖所有 React 视觉布局。当前代码行、分支、函数覆盖率分别为 85.14%、91.61%、90.57%；七个场景另经实际导出抽帧检查。

## 这段样片能证明什么

| 画面 | 来源 | 边界 |
| --- | --- | --- |
| 开场相机 | Base `eval-2004` 的观测序列回放，源片前 8 秒 | 不是实时操作录屏，不是成功片段 |
| 数据采集 | `train-1001` 真实 RGB 回放，前 9 秒 | 剩余时间解释数据字段，不循环源片 |
| 训练曲线 | 历史训练日志绘制的真实结果图 | 不以两个端点伪造完整曲线；损失下降不代表导航提升 |
| 左右模型轨迹 | 同一 `eval-2001` 的位姿、动作与距离记录 | 按共同动作步同步，不是墙钟时间同步，也不冒充原始 RGB |
| 总体结果 | 原始 `eval_result.json` 的完整十条配对评测 | 拦截是深度安全门拒绝前进，不是物理接触次数；SPL 使用直线距离代理 |

真实回放只有各自明确的来源和时长。本样片不声称 75% 连续实录占比，也不使用循环播放凑时长。旁白与字幕时间是制作计划，声音合成后还需重新对齐、试听和响度验收。

## 下一步与发布门

先确认 60–90 秒样片的画面、音色与节奏，再扩为 B 站／知乎 10–12 分钟主片，以及抖音／小红书 2–3 分钟独立竖屏版。四期深度教程暂留后续，不自动排期。

自然沉稳男声优先试听后确定，保留自然停顿和技术词发音；未获声音本人授权不克隆。最终使用 AI 配音时应如实披露，并按平台提供的标识要求处理。未确认许可的音乐不进入成片。

`publicationGate()` 目前必须返回未就绪。该门只覆盖结构、来源存在、配音状态与最终确认；完整解码、素材授权、OCR、音画对应、响度、黑帧和人工终审仍需分别验收。网页登录、验证码和最终提交由用户确认，审核通过后再使用未登录窗口验证公开链接。
