README 首屏只放定位、真实动图和可核实状态，提供“看演示／本地验证／研究复现”三条入口。保留完整指标、限制和许可边界。新视频使用克制留白、少量强调色、全中文解释文字和自然沉稳男声。每段画面必须解释当下旁白，不循环镜头或重复文案凑时长。

区分“操作录屏”“真实数据回放”“真实日志回放”“真实结果图”“示意动画”。旧素材中的 RGB 序列回放和日志排版不计作连续桌面录屏；不把标签比例视为审美验收。没有实际录屏时直接说明缺口，不虚构画面。
