## 关键排障

### USD AABB 投影

在遍历包含 malformed face-varying primvar 的 G2 USD mesh 时，`UsdGeom.BBoxCache` 会请求 SimulationApp clean shutdown，Python 无法捕获可用异常。配置已显式写入 `project_usd_aabbs: false`，健康接口报告 `runtime_safe_fallback_no_usd_aabb`。下一轮应使用兼容资产或离线 USD bbox 导出，再重采全部数据。

### 模型依赖与训练 gate

GPUFree 直连 Hugging Face 超时，改用 `hf-mirror.com` 后 pinned checkpoint 与 SigLIP 已下载。StreamVLN Python 3.9 依赖安装、4 个分片加载和首 batch 进入均已真实发生；兼容补丁解决了 tokenizer 分支，但首 batch 报 `RuntimeError: shape '[-1, 152064]' is invalid for input of size 241878560`，退出码 1。没有 OOM，未切换 4-bit，未生成 adapter。完整结果在 [`stage2_result.json`](../experiments/exp01-baseline/stage2_result.json)，短证据在 [`stage2-failure.log`](../runs/2026-07-13/stage2-failure.log)。
