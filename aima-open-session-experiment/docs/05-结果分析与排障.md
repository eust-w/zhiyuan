| 层次 | 证据 | 结论 |

## 关键排障

### USD AABB 投影

在遍历包含 malformed face-varying primvar 的 G2 USD mesh 时，`UsdGeom.BBoxCache` 会请求 SimulationApp clean shutdown，Python 无法捕获可用异常。配置已显式写入 `project_usd_aabbs: false`，健康接口报告 `runtime_safe_fallback_no_usd_aabb`。下一轮应使用兼容资产或离线 USD bbox 导出，再重采全部数据。

### 模型依赖与训练 gate

GPUFree 直连 Hugging Face 超时，改用 `hf-mirror.com` 后 pinned checkpoint 与 SigLIP 已下载。首次兼容尝试观察到 `RuntimeError: shape '[-1, 152064]' is invalid for input of size 241878560`；在 `initialize_vision_tokenizer` 后对齐 `lm_head.out_features` 后，4 个分片加载、50 步 LoRA 训练和新进程 adapter 重载均退出码 0。没有 OOM，未切换 4-bit；训练日志同时记录了实际的 `train_loss=0.0`。完整结果在 [`stage2_result.json`](../experiments/exp01-baseline/stage2_result.json)，证据摘录在 [`stage2-training.stdout.log`](../runs/2026-07-13/stage2-training.stdout.log) 与 [`stage2-adapter-reload.log`](../runs/2026-07-13/stage2-adapter-reload.log)。
