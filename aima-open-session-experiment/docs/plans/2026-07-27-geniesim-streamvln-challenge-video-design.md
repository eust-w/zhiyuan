# GenieSim × StreamVLN 导航挑战实录视频设计

日期：2026-07-27

状态：已确认

目标成片：10–12 分钟中文横屏主片

## 1. 项目目标

制作一条以真实操作和实验结果为核心的 GenieSim × StreamVLN 导航挑战视频。成片不采用“静态 AI 卡片连续播报”的表达，而是用连续屏幕实录、终端操作、仿真轨迹、数据文件和评测结果构成叙事主体。

视频需要让普通观众理解挑战目标，也要让技术观众能够判断数据、训练和评测是否真实发生。

核心问题：

> 给机器人一句自然语言导航指令，它能否在 GenieSim 场景中持续观察、生成动作并接近目标？

## 2. 内容边界

全片作为独立技术挑战进行介绍，不讨论任何课程、文档或复现关系。

标题、封面、旁白、字幕、画面文字、简介和标签中不得出现以下表述：

- 课程
- PDF
- 指南
- 私有包
- 原样复现
- 等价适配
- 非官方适配
- 是否符合某个课程要求

不通过删减事实来规避边界。成片仍需准确说明：

- 使用 GenieSim 和 G2；
- 使用 `market_00_g2` 场景；
- 使用 NVIDIA L40 48GB；
- 动作空间与安全执行方式；
- 50 条训练轨迹和 10 条 held-out 评测轨迹；
- LoRA 参数、训练步数和损失变化；
- base 与 LoRA 的真实配对结果；
- `success@0.5m` 均为 `0/10`；
- baseline 认证和创新挑战激励。

## 3. 受众与表达风格

主要受众：

- 对具身智能、机器人导航、仿真训练感兴趣的技术爱好者；
- 希望完成 baseline 并进一步创新的参与者；
- 需要快速判断实验真实性和挑战空间的工程人员。

表达原则：

- 以通俗叙事为主，技术证据穿插其中；
- 旁白使用短句和自然停顿，不连续念参数表；
- 参数首次出现时在画面侧栏展示；
- 失败结果直接解释，不包装成成功案例；
- 示意图只负责解释关系，实验结论只来自真实记录。

## 4. 视频结构

目标时长约 11 分 30 秒，允许在 10–12 分钟内根据素材节奏调整。分章时长以自然男声试听为准，不通过异常加速压缩旁白。

### 00:00–01:05 开场挑战

画面快速切换：

- GenieSim 场景；
- G2 头部相机；
- 前进与转向；
- 训练终端；
- base/LoRA 轨迹；
- 目标距离和 blocked 状态。

旁白提出核心问题，不在开场解释历史背景。

### 01:05–02:15 Baseline 闭环

使用短流程动画解释：

```text
自然语言指令
→ StreamVLN 读取相机观测
→ 生成离散动作
→ GenieSim 执行动作
→ 返回新观测
→ 继续推理或停止
```

说明完成 baseline 并通过实际验收后，可按活动规则申请智元认证证书。

### 02:15–03:50 真实操作与控制闭环

连续展示：

- 启动场景；
- 确认 G2 与头部相机；
- STOP、前进、左转、右转；
- 每次动作后等待两个渲染帧；
- RGB、depth、pose 同步更新；
- 接近障碍时前进被拒绝；
- `blocked=true` 时位姿保持不变。

仿真画面实时叠加：

- `action_id`；
- 动作中文名称；
- 目标距离；
- blocked；
- collision；
- 当前轨迹。

### 03:50–05:25 数据采集与数据结构

完整展示一条训练轨迹从 reset 到落盘：

- 3 条冒烟轨迹；
- 训练种子 `1001–1050`；
- 评测种子 `2001–2010`；
- 50 条训练和 10 条 held-out 评测；
- RGB、depth、pose、动作、距离和碰撞。

以目录树方式解释两层数据：

```text
annotations.json
├── episode_id
├── instruction
├── rgb
└── actions

sidecar
├── depth
├── 4×4 pose
├── 完整动作序列
├── blocked / collision
├── target
└── run_id / hash
```

介绍场景几何、5cm 占据栅格、AABB 探针和深度安全门的技术用途，不进行来源对比。

### 05:25–07:00 LoRA 训练过程

使用真实终端和训练图：

- Isaac Python 与 StreamVLN Python 环境隔离；
- dataset-only 检查；
- 单 batch 前后向；
- BF16 完整训练；
- 59 个有效更新步；
- loss 从 `0.4167` 降至 `0.0823`；
- 峰值显存约 `27.19 GiB`；
- adapter 在新进程中重载。

需要明确：

> loss 下降说明优化发生过，adapter 重载说明权重可以使用；它们都不能单独证明机器人已经学会导航。

### 07:00–08:55 Base / LoRA 配对轨迹

使用同一批 10 条 held-out episode：

- 至少完整展示一组 base/LoRA 配对轨迹；
- 其余轨迹使用快速蒙太奇；
- 每帧显示动作、距离、blocked、collision 和轨迹；
- 所有成功和失败都进入汇总。

核心指标：

| 模型 | success@0.5m | success@3m | 平均最终距离 | 安全拒绝 |
|---|---:|---:|---:|---:|
| Base | 0/10 | 2/10 | 3.989m | 132 |
| LoRA | 0/10 | 1/10 | 4.686m | 45 |

结论：

- 模型推理闭环真实运行；
- LoRA 的安全拒绝次数更少；
- LoRA 的平均最终距离没有改善；
- base 与 LoRA 在 0.5m 主指标上均未成功；
- 训练完成与导航成功必须分开判断。

### 08:55–10:30 创新挑战

给出四类挑战：

1. 场景创新：复杂货架、遮挡、动态障碍和多目标任务；
2. 数据创新：自动指令生成、困难样本挖掘和目标相关增强；
3. 算法创新：长期记忆、地图辅助、目标检测和碰撞恢复；
4. 评测创新：路线偏差、动作效率、恢复能力和跨场景泛化。

激励表述：

> 完成 baseline 并通过验收，可获得智元认证证书；在场景、数据、算法或评测上完成可复核创新，还有机会获得算力、技术辅导和项目展示等进一步支持。具体以活动规则和最终评审为准。

### 10:30–11:30 总结

总结三条经验：

1. 控制器成功不等于模型成功；
2. loss 下降不等于导航成功；
3. 失败结果也必须完整进入总体指标。

结尾：

> 真正的挑战，不是做出一段演示，而是让每一个结果都经得起复核。

## 5. 视觉设计

画面比例目标：

- 真实仿真、终端、数据和轨迹实录：不低于 80%；
- 流程图与指标动画：约 15%；
- 章节卡：不超过 5%。

剪辑规则：

- 连续静态画面不超过 4 秒；
- 真实操作保留鼠标、终端输出和状态变化；
- 不使用生成式人物、虚构机器人动作或伪造终端；
- 示意内容明确标注“流程示意”；
- 实验画面明确标注“真实录屏”或“真实结果”；
- 不直接复用参考视频的画面或音频。

## 6. 声音设计

全程使用自然、沉稳的中文男声 TTS。

要求：

- 语速约每分钟 190–220 个汉字；
- 技术参数前后加入自然停顿；
- 避免播音腔、过度激昂和连续排比；
- 数字按中文语境朗读；
- 旁白目标约 `-16 LUFS`；
- 成片峰值不超过 `-1 dBTP`；
- 背景音乐只作氛围，旁白出现时自动降低 10–12dB；
- 动作执行、blocked 和章节切换使用轻量提示音。

## 7. 数据与证据流

指标只从以下文件读取：

```text
experiments/exp02-equivalent-v3/eval_result.json
```

训练结果从阶段结果、训练日志和已保存曲线读取。媒体与数据通过已有 manifest 和 SHA-256 关联，不在脚本或旁白中手填另一套结果。

数据流：

```text
实验结果 JSON / 日志 / 真实媒体
→ 故事板
→ 旁白与字幕
→ 横屏渲染
→ 媒体验收
→ 敏感信息与禁用词扫描
→ 发布候选文件
```

## 8. 异常与降级处理

- 如果某段真实操作没有连续视频，优先使用相邻真实帧配合局部放大，不生成虚假操作；
- 如果 TTS 出现明显机器感，按句重合成，不通过整体加速掩盖；
- 如果训练或评测指标与源 JSON 不一致，渲染立即失败；
- 如果出现账号、邮箱、IP、实例编号或连接信息，必须裁切或打码；
- 如果发现禁用的课程关联词，字幕、旁白脚本、封面、简介和视频 OCR 验收全部失败；
- 如果平台时长或码率限制变化，从同一故事板派生平台版，不直接破坏主片。

## 9. 验收标准

### 内容

- 时长 10–12 分钟；
- 五个重点全部出现：真实操作、数据结构、训练过程、base/LoRA 配对轨迹、创新挑战；
- baseline 认证与创新激励表述完整；
- `success@0.5m = 0/10` 如实呈现；
- 不含课程关联表述。

### 媒体

- 1920×1080、30fps、H.264/AAC；
- 可完整解码；
- 真实素材占比不低于 80%；
- 连续静态画面不超过 4 秒；
- 无一秒以上黑帧；
- 字幕最多两行；
- 旁白响度和峰值通过；
- 无敏感信息。
