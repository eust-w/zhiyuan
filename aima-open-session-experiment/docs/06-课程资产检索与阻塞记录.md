# 06｜课程私有资产与等价实现边界

这页专门回答一个容易混淆的问题：仿真自采可以补什么，不能补什么？

## 不能通过仿真“采回来”的内容

PDF 提到的 `course_tools/`、课程版 `stage0.md…stage3.md`、UDP 12346/12347 协议和课程专用配置属于软件/课程附件，不是传感器数据。没有原文件，就不能通过 RGB-D 反推出原始代码，也不能声称课程原样复现。

本仓库采用独立 loopback HTTP 适配层，且没有修改 `/root/genie_sim`。所有标题和公开材料统一写：

> 流程参考 AIMA 指南，但未使用课程私有适配包。

## 可以自采的等价内容

场景中的视觉和几何观测可以从真实仿真重新采集。本轮用 1762 帧带相机内参与相机世界位姿的 RGB-D 融合出 20 万彩色点，生成点云型：

- `sample.ply`
- `sample.usda`
- `sample.usdz`

三个文件来自同一份点集；USDA 与 USDZ 都在全新 Isaac 进程里重新打开，默认 prim 和 200,000 points 通过。它们的 schema 固定为 `geniesim-self-captured-equivalent/v1`，只叫“自采等价资产”，不叫“课程 sample 原件”。

## 障碍处理的真实边界

计划中的完整视觉 USD AABB 投影在当前 G2/市场资产上会触发 Isaac clean shutdown，因此没有作为“已完成”藏在历史结果里。随后新增的等价 Cube USD 层已独立完成投影验证；最终运行仍采用：

1. 有界 fallback 栅格做 footprint 越界保护；
2. 独立 `runtime_aabb_probe.py` 在 Isaac/PXR 进程中记录 10 个 Cube、8322 原始格和 30478 膨胀格；
3. 头部 depth 中央视野第 10 百分位小于 0.45m 时拒绝前进。

后者已经留下近障碍拒绝与位姿不变证据，也成为 Stage 3 碰撞统计的主要来源，但它与课程私有 AABB planner 不是同一实现。

## 许可边界

本实验没有把 StreamVLN 代码许可推断为 checkpoint 或 adapter 的再分发授权。公开仓库与权重的授权边界在本轮没有完成独立法律核验，因此项目限定为非商业研究演示；基础权重和 adapter 不提交仓库、不上传抖音、不对外再分发。若转为商业宣传，必须另行取得明确授权。
